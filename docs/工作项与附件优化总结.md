# 工作项与附件优化总结

> 文档日期：2026-05-15  
> 关联方案：`docs/权限与菜单设计方案.md`、`question-fix/工作项需求项拆解与团队模块扩展.md`

## 一、目标与背景

在「需求项拆解 + RBAC + 工作台」既有能力上，收敛跨页跳转时的操作区混乱，统一个人侧工作项录入体验，并为验收证据补充可上传、可预览的附件能力（含表格类文件）。

## 二、已实现能力

### 2.1 详情页「返回列表」与列表上下文

- **问题**：从全局工作项或「我的工作台」进入项目内工作项详情后，若一律返回项目工作项列表，会在筛选区看到与首次从该列表进入时不一致的「+ 新建工作项」等操作。
- **做法**：
  - 从 `/work-packages`、工作台链到详情时，在 URL 上携带 `returnTo`（如 `/work-packages`、`/my/page`）。
  - 详情页「返回列表」与面包屑「工作项」链接使用该白名单内的 `returnTo`，避免跳错上下文。

### 2.2 项目工作项列表「新建工作项」

- **做法**：筛选区「新建工作项」仅在当前用户具备 `assignWorkPackages` 能力时展示，避免无权限账号看到误导入口。

### 2.3 我的工作台 · 新建工作项（快速 / 完整）

- **需求项**：与「配置成员」内子任务的需求项交互一致——逐条输入、**+ 新增需求**、可删行；Admin/PM/TeamLead 仍至少 1 条需求（与后端策略一致）。
- **附件**：支持在创建时上传多个小附件；后端与工作项一并持久化。

### 2.4 工作项附件 · 数据与 API

- **模型**：`WorkPackageAttachment`（`workPackageId`、`fileName`、`contentType`、`size`、`dataUrl`、`createdAt`），通过 `WorkPackage.attachments` 关联。
- **实现取向**：演示环境将文件读为 **data URL** 存入 SQLite，避免单独对象存储；单文件 **≤ 2MB**、单工作项 **≤ 5** 个附件（前后端均有约束）。
- **创建**：`POST /api/work-packages` 请求体可带 `attachments: { fileName, contentType, size, dataUrl }[]`。
- **迁移**：`prisma/migrations/20260515133000_work_package_attachments/migration.sql`；本地开发可用 `npx prisma db push` 与 schema 对齐。

### 2.5 详情页 · 附件预览

| 类型 | 预览行为 |
|------|----------|
| 图片 | `<object>` 内嵌，失败时可打开链接 |
| PDF | `<iframe>` |
| CSV / TSV | 解析为表格（带引号字段的简单 CSV 规则），最多展示约 50 行 |
| Excel（.xls / .xlsx） | 不内嵌解析（浏览器限制）；展示说明卡片，**打开** 下载后本地查看 |
| 文本 / JSON | `<pre>` 截断展示 |

上传控件 `accept` 已包含表格与 Excel 的常见扩展名及 MIME。

### 2.6 配置列按钮

- **做法**：「配置列」使用强调色按钮 variant，并增加列图标，提升在表格工具栏中的辨识度。

### 2.7 顶栏「+」新建

- **做法**：按当前是否在项目上下文及权限跳转——有项目且可 `assignWorkPackages` 时指向项目内新建；否则在具备 `createPersonalWorkPackage` 时指向 `/my/work-packages/new`；否则不展示占位按钮，减少跨菜单后的无效入口。

### 2.8 复用组件

- **`components/work-packages/WorkPackageFormFields.tsx`**：`RequirementListEditor`、`AttachmentPicker`、`normalizeRequirementItems` 等，供项目创建表单与个人表单共用。

## 四、验证建议

1. **数据库**：迁移已应用或执行 `npx prisma db push`。  
2. **功能**：工作台快速新建 → 带附件 → 详情预览；从全局工作项进详情再返回；上传 `.csv`/`.xlsx` 检查预览/说明与打开下载。  
3. **工程**：`npx prisma validate`、`npx tsc --noEmit`；按需 `npm run lint`、`npm run test`。

## 五、后续可演进（未做）

- Excel 内嵌预览需引入专用解析库（如 SheetJS）或后端转 HTML/PDF，并评估体积与许可。  
- 生产环境建议对象存储 + 短链/签名 URL，替代 DB 存 data URL。  
- 大文件与病毒扫描、MIME 魔数校验等安全加固。
